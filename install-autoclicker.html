🎯 2-Spot Auto Clicker

Clicks between two spots lightning fast

Step 1: Open PowerShell as Admin

Right-click Start → Windows PowerShell (Admin) → Yes

Step 2: Paste this command

Invoke-WebRequest -Uri "https://raw.githubusercontent.com/rotstrucking1-prog/Rotstrucking-app1/main/autoclicker.py" -OutFile "C:\RoatBot\autoclicker.py"

Step 3: Run it

C:\Python314\python.exe C:\RoatBot\autoclicker.py

Want faster/slower? Add --delay (seconds):

C:\Python314\python.exe C:\RoatBot\autoclicker.py --delay 0.03

🎮 Controls

F9Set Spot 1 — hover your mouse over the ITEM, press F9
F10Set Spot 2 — hover your mouse over the FIRE, press F10
F11START / STOP clicking
F12QUIT

⚡ Quick Shortcut (Optional)

To make a desktop shortcut, paste this in PowerShell:

$ws = (New-Object -ComObject WScript.Shell); $sc = $ws.CreateShortcut("$env:USERPROFILE\Desktop\AutoClicker.lnk"); $sc.TargetPath = "C:\Python314\python.exe"; $sc.Arguments = "C:\RoatBot\autoclicker.py"; $sc.WorkingDirectory = "C:\RoatBot"; $sc.Save(); Write-Host "Desktop shortcut created!"
