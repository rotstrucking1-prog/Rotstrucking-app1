ROAT PKZ DECIMATOR v4.0

PVP Assist Tool — Tribrid Gear Switches + Spec Combo

1 Open PowerShell as Admin on your PC, then paste this:
mkdir -Force "$env:USERPROFILE\Desktop\RoatBot\templates" | Out-Null; Invoke-WebRequest -Uri "https://raw.githubusercontent.com/rotstrucking1-prog/Rotstrucking-app1/main/decimator_v4.py" -OutFile "$env:USERPROFILE\Desktop\RoatBot\bot.py" -UseBasicParsing; Write-Host "Downloaded! Run: cd $env:USERPROFILE\Desktop\RoatBot && python bot.py" -ForegroundColor Green
2 Install dependencies (one time only):
C:\Python314\python.exe -m pip install opencv-python numpy pillow pynput
3 Run the bot:
cd $env:USERPROFILE\Desktop\RoatBot; C:\Python314\python.exe bot.py
4 First run — LEARN MODE:
  1. Open Roat Pkz and make sure your tribrid gear is in your inventory
  2. Press F11 — bot screenshots your inventory
  3. Click AUTO-ASSIGN (5/4/4) — assigns top 5 = Melee, next 4 = Mage, last 4 = Range
  4. Or click individual slots to cycle: Melee(W) → Mage(Q) → Range(E) → unassigned
  5. Click SAVE & CLOSE — done! Templates saved permanently.

Hotkeys

QMagic switch — equip mage gear + open spellbook + pre-select Ice Barrage WMelee switch — equip melee gear + combat tab ERange switch — equip range gear RSPEC COMBO — melee gear + spec weapon + spec bar + click target F11Learn Mode — re-assign gear at any time F12Pause / Resume toggle
NOTES:
  • Q/W/E/R only fire when Roat Pkz window is focused — safe to type elsewhere
  • Spec weapon selected from GUI dropdown (AGS default)
  • Templates persist between sessions — learn once, switch forever
  • Bot finds items by their ICON, not slot position — works even when items move
