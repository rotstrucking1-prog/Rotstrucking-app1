  1. Open PowerShell on laptop (right-click Start → PowerShell)
  2. Tap the blue button below to COPY
  3. Paste into PowerShell → press Enter
  4. Wait ~30 seconds — app will launch automatically!

⚠️ If PowerShell asks about execution policy, type Y and press Enter

powershell -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/rotstrucking1-prog/Rotstrucking-app1/main/obd2/install_obd2.ps1' -OutFile $env:TEMP\install_obd2.ps1; Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force; & $env:TEMP\install_obd2.ps1"
