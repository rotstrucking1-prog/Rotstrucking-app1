🚗 OBD2 Dashboard Installer

2009 VW Jetta TDI — Vgate vLinker FS

1Open PowerShell as Admin

Right-click the Start button → Windows PowerShell (Admin)

Or search "PowerShell" → right-click → Run as Administrator

2Copy This Command
Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/rotstrucking1-prog/Rotstrucking-app1/main/install_obd2.ps1 | iex
3Paste & Run

Click inside PowerShell → Right-click to paste → Press Enter

It will download the dashboard, install dependencies, and create a desktop shortcut.

⚠️ Before launching:
1. Plug Vgate USB into laptop
2. Plug Vgate OBD2 end into Jetta (under dash, driver side)
3. Turn ignition ON (key to ON position — engine can be off or running)
🔧 For ABS Brake Bleeding:
Use your XTOOL A30M with the Anyscan app → Special Functions → ABS Bleeding.
The Vgate adapter reads engine data; the XTOOL handles the ABS module.
